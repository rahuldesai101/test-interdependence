# Cognitive Architectures

A **Cognitive Architecture** is a blueprinted structure for artificial general intelligence that unifies perception, memory, reasoning, and action execution into a single coherent system.

## Key Components

1. **Working Memory:** The active scratchpad for short-term reasoning and context retention.
2. **Procedural Memory:** Stored operational routines and skill routines, often represented as [[03_procedural_skills]].
3. **Episodic & Semantic Memory:** Long-term storage of experiences and structured world facts, organized efficiently using a [[02_knowledge_graphs|Knowledge Graph]].

## Goal-Oriented Loops

Modern cognitive engines rely on active goal tracking to prevent ambient memory drift. The system constantly compares its current state against an [[04_active_goals|Active Goal]] to determine the next logical execution step.
